# Español Benidorm — дизайн (спецификация)

Дата: 2026-06-22
Статус: утверждён к реализации (v1)

## 1. Цель

Личное PWA-приложение для изучения испанского языка для одного пользователя
(уровень A2–B1), живущего в Валенсийском сообществе рядом с Бенидормом. Акцент —
быстрый прогресс, удобство, ежедневная практика и **местный (валенсийский/
аликантийский) вариант разговорного испанского**.

Не многопользовательское. Без аккаунтов и логина.

## 2. Ключевые решения (зафиксированы в брейнсторме)

| Решение | Выбор |
|---|---|
| AI-движок | Claude API (грамматика, диалоги, автозаполнение, коучинг речи) |
| Хранение API-ключа | Только на телефоне (вводится один раз в Настройках) |
| Напоминания | Отложено: web-push убран из scope; пользователь настраивает через Календарь/Напоминания iOS вручную |
| Целевая платформа (сейчас) | Chrome (десктоп) — полная поддержка Web Speech API, включая распознавание речи для «Логопеда». iOS-установка позже. |
| Уровень ученика | A2–B1 |
| Технический подход | Чистый PWA без сборки, IndexedDB, Web Speech API, Service Worker |
| Оценка произношения | Разборчивость (браузерное распознавание) + AI-коучинг |

## 3. Архитектура

Чистый клиентский **PWA** из статичных файлов. Бэкенда нет.

- Устанавливается на iPhone: Safari → «Поделиться» → «На экран Домой».
- Запросы к Claude API напрямую из браузера, ключ пользователя, заголовок
  `anthropic-dangerous-direct-browser-access: true`.
- Озвучка — Web Speech API `SpeechSynthesis` (голос `es-ES`, бесплатно).
- Распознавание речи — Web Speech API `SpeechRecognition` (`es-ES`).
- Хранилище — IndexedDB (словарь, состояние SRS, история, настройки, лог ошибок).
- Service Worker — офлайн-оболочка + push-напоминания.
- Хостинг — GitHub Pages (бесплатно).

### Модель и стоимость

По умолчанию `claude-haiku-4-5` (дёшево/быстро: грамматика, автозаполнение,
коучинг), для диалогов опционально `claude-sonnet-4-6`. Модель выбирается в
Настройках. Расход — центы за активное использование.

## 4. Экраны (нижняя панель вкладок, интерфейс на русском)

5 видимых вкладок с группировкой:

1. **Учить** — SRS-очередь повторения на сегодня
2. **Словарь** — двусторонний перевод RU→ES и ES→RU + добавление слов
3. **Речь** — подвкладки: **Аудио** (диалоги на слух) и **Логопед** (фонетика/произношение)
4. **Грамматика** — проверка фраз
5. **Ещё** — Прогресс, Настройки

## 5. Модули (каждый — отдельный файл, одна задача)

- `app.js` — оболочка, hash-роутер, **реестр модулей** (см. §9 Расширяемость)
- `claude.js` — клиент API: `checkGrammar()`, `generateDialogue()`, `enrichWord()`,
  `gradeAnswer()`, `gradeSpeech()`
- `db.js` — обёртка IndexedDB + версионирование схемы (миграции)
- `srs.js` — интервальное повторение (SM-2-lite), чистые функции (юнит-тесты)
- `dictionary.js` — двусторонний перевод (RU→ES и ES→RU, переключатель
  направления + автоопределение языка ввода), автозаполнение карточки, CRUD слов
- `listening.js` — генерация диалога + TTS-воспроизведение + вопрос на понимание
- `speech.js` — **Логопед**: чтение вслух, оценка разборчивости, AI-коучинг,
  упражнения (минимальные пары, скороговорки, ударения), ораторские заметки
- `grammar.js` — проверка фразы + объяснение по-русски + лог ошибок в «слабые темы»
- `reminders.js` — ежедневное локальное уведомление по расписанию
- `progress.js` — стрик, выучено слов, очередь на сегодня, слабые темы
- `settings.js` — API-ключ, время напоминания, уровень, голос, модель
- `prompts.js` — системные промпты, включая диалект и фонетический коучинг

## 6. Потоки данных

- **Слово:** ввод RU или ES → `enrichWord` (перевод, пример, род, спряжение,
  местный вариант) → превью карточки → сохранение в IndexedDB → в SRS-очередь.
- **Повторение:** напоминание → открытие → очередь «на сегодня» → оценка ответа
  обновляет расписание SRS.
- **Аудио:** тема (выбор/авто) → Claude генерит диалог с местным колоритом →
  TTS-озвучка → транскрипт по кнопке → вопрос на понимание.
- **Грамматика:** ввод фразы → Claude правит → объяснение по-русски → ошибка
  пишется в слабые темы.
- **Логопед:** эталонная фраза → запись речи (SpeechRecognition) → сравнение с
  эталоном = оценка разборчивости (% совпадения) → `gradeSpeech` (Claude): какие
  звуки хромают, советы по ударениям/темпу/паузам/интонации + упражнение.

## 7. Диалект (Бенидорм / Валенсия)

Общий системный промпт инструктирует Claude: база — стандартный кастильский
испанский, но подсвечивать местные валенсийские/аликантийские словечки,
выражения района Бенидорма, помечать отличия; уровень A2–B1. Фонетический промпт
учитывает звуки, сложные именно для русскоязычных (раскатистое `rr`, межзубное
`c/z`, мягкие `ll/y`) и местный выговор.

## 8. Обработка ошибок

- Нет API-ключа → подсказка перейти в Настройки.
- Нет сети → словарь и SRS работают офлайн; AI-функции мягко сообщают об ошибке.
- Нет голоса `es` / нет распознавания → текстовый fallback.
- Ошибки API (лимит, неверный ключ) → понятное сообщение.
- iOS push: карточка-инструкция «добавь на экран Домой и разреши уведомления»;
  деградация до внутреннего напоминания.

## 9. Расширяемость (на будущее)

Чтобы новые блоки добавлялись легко, без переписывания ядра:

- **Реестр модулей.** `app.js` хранит массив `features`. Каждый модуль
  регистрируется объектом: `{ id, title, icon, group, render(container), order }`.
  Добавить новый блок = создать `js/<name>.js`, вызвать `registerFeature({...})`,
  подключить `<script>`. Навигация и роутинг строятся из реестра автоматически.
- **Реестр типов упражнений.** SRS и Логопед используют общий список типов
  упражнений (`exerciseTypes`), каждый со своим `render` и `grade`. Новый тип
  упражнения добавляется регистрацией, без правки очереди.
- **Версионирование схемы БД.** `db.js` хранит `DB_VERSION` и применяет миграции
  по возрастанию. Новые поля карточки / новые хранилища добавляются миграцией, не
  ломая существующие данные.
- **Промпты вынесены в `prompts.js`** — добавление нового AI-сценария = новая
  функция-промпт, ядро не трогается.
- **Экспорт/импорт данных** (JSON) закладывается в `db.js` как точка для будущего
  бэкапа/синка.

## 14. Новые блоки (2026-06-22)

### План 5 — «5 слов в день» (ежедневная привычка)
Вкладка «5 слов» (order 15). Каждый день AI подбирает 5 новых практичных разговорных
слов/выражений для повседневной жизни в Бенидорме, исключая уже известные пользователю
(передаётся список его слов). По слову: перевод, пример с переводом, местная заметка,
озвучка. Действия: «Добавить в словарь» (→ в SRS-повторение) и «Применить» (написать
своё предложение → AI-проверка). Прогресс дня «добавлено N/5», день засчитывается в
стрик. Набор дня хранится в `settings` по ключу `daily-YYYY-MM-DD` (без миграции БД).

### План 6 — Ассистент-учитель + адаптивные грамматические уроки
Вкладка «Учитель» (самая верхняя). «Профиль уровня» вычисляется автоматически из данных
(слабые темы из `mistakes`, число выученных слов, динамика повторения) и передаётся
ассистенту. Ассистент выбирает следующую тему по слабым местам, генерит урок (объяснение
по-русски + 3–5 упражнений), проверяет ответы, обновляет профиль и историю уроков.

## 15. Обновление «продуктивность и удовольствие» (2026-10-04)

1. **Единый журнал ошибок** (`mistakes.js`): ошибки из грамматики, уроков, заданий, «5 слов»,
   чата (извлекаются вместе с памятью наставника, без отдельного запроса) и сценок пишутся в
   `mistakes` с полем `source`. «Слабые темы» и подбор уроков опираются на все режимы.
2. **Слово по нажатию** (`wordpick.js`): испанские слова в диалогах, чате, уроках, заданиях и
   сценках кликабельны → перевод с учётом контекста, озвучка, «＋ в словарь» (с проверкой дублей).
3. **Типы карточек** (`exercises.js`): ru→es, es→ru, на слух, ввод, пропуск в примере, вслух.
   Новое слово сначала показывается классической карточкой. Режим «только классические» — в Настройках.
4. **FSRS + дневные лимиты** (`fsrs.js`, `queue.js`): алгоритм FSRS-5 с весами по умолчанию,
   4 оценки с подписью интервала, старые SM-2 карточки конвертируются без потери прогресса.
   Лимиты новых/повторений в день (по умолчанию 10/50), кнопка «Позаниматься ещё».
5. **Цель дня и заморозки** (`activity.js`, `stats.js`): 3 шага (повторение, 5 слов, живая практика),
   шкала прогресса; каждые 7 дней серии дают ❄️ (макс. 2), которая спасает один пропуск.
6. **Сценки** (`roleplay.js`): 10 ситуаций Бенидорма, ИИ в роли, подсказки и перевод реплик,
   голосовой ввод, разбор с оценкой, исправлениями (→ журнал ошибок) и словами (→ словарь).
7. **Аудио**: повтор и замедление каждой фразы, диктант с пословной проверкой, своя тема.
8. **Прогресс**: графики повторений за 14 дней и прогноза на 7 дней, точность, источники слабых тем.
9. **Модели**: отдельные модели для быстрых задач (по умолчанию Haiku 4.5) и для разговора
   (по умолчанию Sonnet 5.5); `claude-sonnet-4-6` автоматически заменяется на `claude-sonnet-5-5`.
   Для Sonnet 5.5 размышления выключены (`thinking: between_tools`), `effort: low`,
   серверный fallback при отказе; при 400 запрос повторяется без этих полей.
10. **Кэш промпта**: автоматический `cache_control` в чате и сценках; профиль фиксируется на беседу,
    окно истории и обрезка сдвигаются «ступеньками» по 10 сообщений, чтобы начало запроса не менялось.
    Для Haiku 4.5 кэш срабатывает только от 4096 токенов, т.е. в длинных беседах.
11. **Напоминания без сервера** (`reminders.js`): .ics-событие на каждый день в выбранное время
    + число карточек на иконке (Badging API). Настоящий web-push потребовал бы сервер — отложено.

## 16. «Книга» — чтение по фото (2026-10-04)

Раздел `reader.js` (*Lectura*): фото страницы (камера или галерея) уменьшается на устройстве до 1600 px
по длинной стороне (JPEG) и отправляется в Claude (модель для разговора) как изображение. Ответ —
JSON: распознанный текст по абзацам, перевод каждого абзаца, смысл страницы, 8–15 новых слов в словарной
форме с примером из текста (известные ученику слова исключаются), 1–3 грамматические конструкции,
примерный уровень. Текст кликабелен (слово по нажатию), абзацы озвучиваются, слова добавляются в словарь
с пометкой книги, по странице можно задавать вопросы. Страницы (без фото) хранятся в `readerPages`
(последние 30) и синхронизируются; чтение засчитывается в «Живую практику».

## 17. Быстрая запись услышанного слова (2026-10-04)

`capture.js`: плавающая кнопка «＋ слово» на всех экранах (кроме чата и сценок). Панель: микрофон (es-ES),
поле «как услышал» (ошибки, слитно, кириллица, описание по-русски), «где услышал». Запись сразу ложится
во «Входящие» (`inbox`), разбор в фоне (`CAPTURE_SYSTEM`, быстрая модель): уверенно — слово сразу в словаре
(тост с «Отменить», «Не то?» → выбор из вариантов), иначе 2–3 варианта на выбор; без сети — статус
«разберу позже», повтор при событии `online` и при запуске. «Входящие» синхронизируются. Ссылка `#capture`
открывает панель сразу (manifest shortcut для Android/Chrome).
Ссылка `#capture/<слово>` сразу записывает слово (для команды iPhone: «Диктовать текст» → «Открыть URL»).
Команды iPhone открывают ссылку в Safari, у которого память отдельная от приложения на экране «Домой»,
поэтому запись доезжает до приложения через синхронизацию; приложение после каждой синхронизации
(запуск и возврат на экран) само разбирает пришедшие записи. Service worker обслуживает только
собственные файлы приложения, запросы к API идут напрямую.

## 18. Этап 1 аудита — надёжность (2026-10-05)

- **Синхронизация без дублей.** У слова есть постоянный `uid` и время изменения `updatedAt` (ставит `putWord`).
  Применение снимка (`replaceWordsPreservingIds`) сохраняет числовые id существующих слов, сопоставляя по `uid`
  или по слову, — открытый экран «Учить» больше не создаёт копию слова. Свежесть при слиянии — по `updatedAt`,
  без него — по прежним правилам (lastReview, затем reps/due/createdAt).
- **Удаления не воскресают.** `deleteWord` пишет пометку `{key, uid, at}` в `deletedWords` (последние 500,
  синхронизируются объединением). Слово отбрасывается, если пометка новее его `updatedAt`/`createdAt`.
- **autoSync без гонок:** одна синхронизация за раз, вызовы во время работы схлопываются в один повтор;
  если объединённый снимок совпадает с облаком, запись не выполняется.
- **Резервная копия** (Настройки): скачать JSON без ключей `espanol-backup-ГГГГ-ММ-ДД.json`; восстановление
  объединяет файл с текущими данными. При запуске — `navigator.storage.persist()`.
- **Structured outputs** (`schemas.js`): все 16 JSON-ответов модели идут с `output_config.format`
  (json_schema, все поля обязательны, `additionalProperties: false`); при 400 — повтор без схемы, `extractJson`
  остаётся подстраховкой.
- **Проверка ключей урока:** после генерации урок нормализуется, вторая модель (модель для разговора) решает
  упражнения и исправляет неверные `answer`/`expected` до показа ученику; при ошибке проверки урок показывается как есть.
- **Кэш озвучки** ограничен 500 фразами (старые удаляются).
- **CI:** `.github/workflows/test.yml` (node --test); тест, что `sw.js` кэширует все модули и шрифты.

## 19. Этап 2 аудита — маршрут (2026-10-05)

- **5 вкладок вместо 14 разделов** (`app.js`: `TABS`, `tabOf`): Сегодня (занятие, 5 слов) · Повторить ·
  Практика (меню-плитки: сценки, книга, аудио, логопед, задания — `practice.js`) · Наставник (чат, уроки курса,
  проверка фразы — переключатель сверху, вкладка помнит последний вид) · Словарь. Прогресс и Настройки —
  через кнопку профиля в верхней панели; на вложенных экранах сверху ссылка «‹ Вкладка».
- **«Занятие на 15 минут»** (`session.js`): план из состояния дня — повторение (до 20 карточек), слова дня,
  одна живая практика (по дням чередуются сценка / аудио / книга / урок курса), итог. Шаги — обычные экраны;
  полоска занятия в верхней панели показывает шаг и прогресс (по счётчикам активности от старта занятия,
  событие `es-activity`) и кнопку «Дальше/Пропустить». Состояние — в localStorage на текущий день (не синхронизируется).
- **Словарь**: поиск по испанскому и русскому без учёта ударений, фильтры (Трудные — 4+ провала, Новые, Улица,
  Книга, Сценки), правка всех полей, удаление с подтверждением; у новых слов поле `source`
  (street/book/scene/daily/tap/manual), у старых источник угадывается по заметке. Переименование слова оставляет
  пометку удаления старого написания для синхронизации.
- **Первое знакомство** (`onboarding.js`): ключ Claude (с проверкой) → уровень → цель (идёт в программу курса).
- **Доступность**: зоны нажатия от 44 px, шрифты в rem от системного размера текста iPhone (`-apple-system-body`),
  иконки с `aria-label` вместо эмодзи-кнопок, `lang="es"` на испанском тексте для VoiceOver, `aria-current` во вкладках,
  уменьшение анимаций по системной настройке. В «Повторении»: пробел/Enter — ответ, 1–4 — оценка.
- Долгие запросы (страница книги, урок) показывают сменяющиеся шаги и секунды.

## 20. Этап 3 аудита — грамматика как навык (2026-10-05)

- **Виды карточек в одной очереди FSRS.** Поле `kind`: нет — слово словаря; `verb` — глагол во времени;
  `fix` — «Исправьте фразу». Ключ слияния и пометок удаления — `wordKey` (`kind:es`), словарь, «5 слов»,
  книга и статистика берут только слова (`getVocab`).
- **Ошибки → карточки** (`mistakes.js: makeFixCard`): каждая ошибка из чата, уроков, сценок, проверки фраз,
  заданий и тренажёров становится карточкой (если исправление — фраза из 2+ слов и отличается от ошибки).
  В уроке выбор варианта в предложении с пропуском сохраняется целой фразой.
- **Тренажёр глаголов** (`verbs.js`): спряжение по правилам — 43 частых глагола, 5 времён (presente, perfecto,
  indefinido, imperfecto, futuro), с vosotros, неправильные основы, чередования, орфография (-car/-gar/-zar),
  неправильные причастия. Карточка = глагол + время, лицо выбирается при каждом показе; ответ без ударения — «почти»;
  на обороте — таблица спряжения. В «Тренажёрах» — «＋10 глаголов» по каждому времени и разминка без влияния на расписание.
- **Артикль и род**: тип карточки «el или la?» (клавиши E/L), письменный ответ без артикля или с чужим — «почти»
  с подсказкой; артикль подсвечивается цветом (el — бирюзовый, la — апельсиновый) в повторении и словаре.
- **Наборы** (`sets.js`): 50 ложных друзей для русскоязычных (la familia, la carta, el instituto…), 30 слов с
  «неожиданным» родом (la mano, el problema, el agua, la leche…), 24 пары ser/estar и 22 por/para с объяснениями.
  Раунд из 10 вопросов; ошибки уходят в карточки «Исправьте фразу».
- Экран `#drills` («Тренажёры») во вкладке «Повторить», ссылка — под карточкой повторения.

## 21. Этап 4 аудита — личный испанский (2026-10-05)

- **Частотный словарь** (`freq.js`): 1000 самых частых знаменательных слов (без служебных) в словарной форме,
  три группы (топ-250, 251–500, 501–1000; порядок внутри приблизительный). Покрытие «в словаре / выучено»
  считается по словам и глаголам тренажёра, показывается в «Прогрессе». «5 слов дня» получают 12 следующих
  незнакомых частых слов как кандидатов, истории — 3 новых слова отсюда.
- **Модель ученика** (`profile.js: buildProfile`): уровень, результат теста, цель, слова, покрытие частотного словаря,
  уверенность во временах (по карточкам глаголов), 8 слабых тем, заметка учителя, память — уходит в уроки, курс, чат, задания.
- **Темы по уровням** (`curriculum.js`): перечень A1–B2 по мотивам Plan Curricular Института Сервантеса + 3 общие темы.
  Это единый список тем ошибок: в схемах ответа (проверка фразы, задания, память чата, разбор сценки) тема — enum.
  Курс Учителя строится по темам уровня ученика; в «Слабых темах» у темы виден уровень.
- **Тест уровня** (`placement.js`, `#placement`): 24 вопроса (по 6 на A1–B2) с «Не знаю»; уровень — последний
  пройденный подряд (4+ из 6). Доступен из мастера знакомства, Настроек и Прогресса.
- **Истории** (`stories.js`, `#stories`, вкладка «Практика»): 3–4 абзаца из знакомых слов + 2–3 новых частых, перевод,
  озвучка (обычная и медленная), слово по нажатию, новые слова в словарь, вопрос на понимание; хранятся последние 20
  (`stories`, слияние по id). Чередуются в «Занятии на 15 минут».
- **Логопед** (`speech.js`, `phonetics.js`): пары звуков на слух (r/rr, ударение, s — c/z, n — ñ), повтор за голосом
  (образец → микрофон включается сам → сравнение по словам), разбор фразы ИИ; подсказки по фразе под типичные
  ошибки русскоязычных.
- **Разговор без рук** в сценках: персонаж говорит (`speakAndWait`) → распознавание → отправка; два «не расслышал»
  подряд — пауза.

## 22. Голос, микрофон, камера — техническая доводка (2026-10-05)

- **Озвучка Google**: LINEAR16 (WAV, 24 кГц) вместо MP3 32 кбит/с — заметно чище звук; кэш `espanol-tts-v2`
  (старый удаляет service worker). Скорость речи — параметр `speakingRate` на стороне Google (естественнее,
  чем ускорять запись); если голос его не принимает — запасной вариант через `playbackRate` с сохранением тона.
  Поддерживаются любые голоса es-ES (короткое имя Chirp 3 HD или полное имя Studio/Neural2/WaveNet).
- **Экран «Голос и микрофон»** (`voice.js`, `#voice`, меню профиля): живой список голосов Google (`/v1/voices`,
  кэш на неделю) с характером голоса, прослушиванием своей фразы и выбором одним нажатием; основной голос;
  скорость (0.85–1.1); голос телефона с подсказкой про «улучшенные» голоса iOS; движок распознавания и проверка микрофона.
  Из Настроек голосовые поля перенесены сюда.
- **Распознавание речи** (`asr.js`): движки «Авто / Google / Телефон». Google Speech-to-Text v1 (`latest_short`,
  LINEAR16 16 кГц, подсказка ожидаемой фразой, 3 варианта): запись через getUserMedia с шумоподавлением, детектор
  речи по громкости (калибровка шума, конец фразы — 1,1 с тишины, без речи — 7 с, максимум 15 с). Телефон: промежуточный
  текст на экране, 3 варианта, выбор ближайшего к ожидаемой фразе. Общая панель «Слушаю» с громкостью/текстом,
  «Готово» и «Отмена»; понятные сообщения об ошибках; при отказе Google (API не включён, ключ ограничен) — переход
  на распознавание телефона. iOS: режим аудиосессии `play-and-record` на время записи и `playback` для голоса
  (иначе после микрофона звук тихий, «в трубку»).
- **Камера в «Книге»** (`photo.js`): после съёмки — превью и проверка: темно/пересвет (средняя яркость), размытость
  (дисперсия лапласиана), маленькое фото; на развороте — выбор левой/правой страницы (буквы крупнее); поворот на 90°;
  автоконтраст для тусклых фото; отправка до 1568 px (предел Claude), JPEG 0.9.

## 23. Push-напоминания (2026-10-05)

- **Экран «Напоминания»** (`notify.js`, `#notify`, меню профиля): шаги (приложение на экране «Домой», синхронизация,
  разрешение, первое напоминание), время утром и вечером, «вечером — только если ещё не занимался», пример уведомления,
  запасной вариант — событие в календаре (.ics). Старый блок «Напоминание» в Настройках заменён ссылкой.
- **Подписка**: ключи VAPID создаются на телефоне (WebCrypto ECDSA P-256) и не синхронизируются; подписка, время и часовой
  пояс пишутся в строку `код:push` таблицы `sync` в Supabase. При запуске подписка обновляется, если iOS её сменил.
- **Отправка**: GitHub Actions (`.github/workflows/remind.yml`, каждые 30 минут, `scripts/remind.mjs` + `web-push`).
  Конфигурация — один секрет `PUSH_CONFIG` (JSON: Supabase URL/ключ/код + ключи VAPID), его показывает приложение.
  Окно отправки — 3 часа после выбранного времени, состояние (`last_morning`, `last_evening`) — в строке `код:push-state`.
  Текст строится из снимка синхронизации (`scripts/remind-core.mjs`): карточки на сегодня, серия, слова дня, фраза дня;
  вечером — только если сегодня не было занятий. Ручной запуск «Run workflow» с `test` присылает проверочное уведомление.
- **Service worker**: события `push` (показ уведомления) и `notificationclick` (открыть приложение на «Занятии»).
